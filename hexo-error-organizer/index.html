Hexo 报错信息整理器

一个纯前端 Hexo 报错信息整理器，把命令输出整理成适合发给 Codex 的排查清单，不上传、不保存、不联网。

这个小工具把 Hexo 构建或部署报错整理成一份适合发给 Codex 的排查清单。

它只在浏览器本地运行，不上传、不保存、不联网。请不要粘贴密钥、Token、Cookie、私有仓库地址或任何敏感信息。

整理结果只在浏览器本地生成，不上传、不保存。

整理结果

粘贴日志后点击“生成排查清单”。
下一步

复制整理结果不等于提交请求、创建工单或形成服务关系。日志和整理结果仍只在浏览器本地处理，不上传、不保存、没有后端。

  • 需要补全目标、环境和边界：使用 支持请求格式化器。
  • 想手动整理完整请求：查看 支持请求 Intake 模板。
  • 仍然需要联系或自愿支持：阅读 支持与合作 的边界说明。

输出会包含什么

  • 可能执行的命令。
  • 疑似问题类型。
  • 需要补充的目标、环境、最近变更和相关文件。
  • 完整日志占位。
  • 可复制给 Codex 的下一步提示词。

边界

  • 不自动判断真实根因，只做信息整理。
  • 不读取本地文件，不上传日志，不保存内容。
  • 不处理密钥、Token、Cookie、私有地址或隐私数据。
  • 输出结果仍需要你自己检查后再发送。
