支持与合作

支持樂書博客，或提交小范围技术问题，让 yueshu 尝试用 Codex 辅助排查和整理建议。

如果这个博客的文章帮你节省了时间，欢迎打赏支持。打赏不附带交付承诺，只是对内容的认可。

如果你有明确的小范围技术问题，也可以邮件联系我。但这里不是正式外包服务，我本人不承诺独立提供咨询、审计或开发交付。能做的是在你提供足够上下文后，尝试用 Codex 辅助排查、整理步骤或生成建议，最终结果需要你自己确认。

如果不确定应该看哪一页，先从 自助资源导航 选择路径。

提交前建议先使用 支持请求 Intake 模板 整理目标、环境、已尝试步骤、预期结果、实际结果和敏感信息移除情况。这样能减少来回追问，也能更早判断是否不适合继续处理。

可以尝试的事项

  • Hexo / GitHub Pages 构建失败、主题配置、搜索、评论、部署异常的排查思路。
  • AI Agent、Codex、Skills、提示词工作流的资料整理和可执行步骤拆解。
  • 小型代码片段或公开仓库的结构阅读、明显问题提示和修改建议。
  • 技术文章、配置文档、排查记录的整理和润色。

请先邮件说明目标、现状、仓库或页面链接，以及你已经尝试过的步骤。复杂任务、生产系统、隐私数据、正式安全审计和需要结果担保的工作，不适合通过这里处理。

如果不知道怎么描述问题，可以先复制 支持请求 Intake 模板。
