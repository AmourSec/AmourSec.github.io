自助资源导航

按读者目标整理博客里的自助工具、模板、支持入口、变现实验和外部机会清单，帮助快速找到下一步。

如果你不知道该从哪里开始，先按自己的目标选一条路径。

这个导航页只整理现有公开资源，不提交请求、不处理付款、不联系第三方，也不代表任何咨询、审计或交付承诺。

我有 Hexo / 构建问题

第一步：用 Hexo 报错信息整理器 把日志整理成可排查清单。

然后看：

  • Codex 辅助问题排查模板包：整理环境、命令、报错和复现步骤。
  • 支持请求格式化器：把问题改成可复制 intake 文本。
  • 支持请求 Intake 模板：确认是否缺少目标、环境、链接和边界说明。

不要粘贴 Token、Cookie、私有仓库地址、客户数据或公司内部日志。

我需要格式化支持请求

第一步：打开 支持请求格式化器，填写目标、上下文、环境、尝试步骤、预期结果和实际结果。

然后看：

  • 支持请求 Intake 模板：复制完整字段结构。
  • 支持请求分流与回复草稿：判断请求是自助、需补充信息、小范围查看，还是应该婉拒。
  • 支持与合作：如果仍然合适，再决定是否联系或自愿支持。

发送任何请求前都要先脱敏。

我想要可复用模板

第一步：看 Codex Workflow Template Pack 的定位和适用场景。

然后看：

  • 本地模板包文件清单：查看当前 Markdown 文件组成。
  • 模板包预览素材计划：查看未来预览图要呈现什么。
  • 模板包上架文案草稿：查看未来可能上架时的文案和边界。

当前模板包仍是本地草稿，没有下载入口、价格、checkout 或平台 listing。

我想理解这个变现实验

第一步：阅读 变现实验。

然后看：

  • 内容机会 Backlog：查看后续长尾内容选题和优先级。
  • 外部机会观察清单：了解当前机会类别、限制和最小下一步。
  • 外部候选机会任务表：查看 AI 赏金、模板市场和小工具目录的候选观察入口。
  • 可下载式模板包目录结构草案：看产品化路径如何从内容沉淀到文件包。

实验目标是合规准备和验证，不是自动对外接单或自动赚钱承诺。

我想支持这个博客

第一步：打开 支持与合作。

可以做的事：

  • 自愿打赏支持已有内容。
  • 发送小范围、已脱敏、上下文完整的问题。
  • 指出文章或工具里可以改进的地方。

打赏不是购买服务，不附带交付、咨询、审计、售后或结果保证。

我想观察外部机会

第一步：看 外部机会观察清单。

然后看：

  • 外部候选机会任务表：拆成 AI 赏金、模板市场、小工具发布渠道三类候选。
  • 模板包上架文案草稿：了解哪些材料能先本地准备。
  • 变现实验：看当前公开实验记录。

外部机会只做观察和准备。账号注册、提交、PR、投递、发布、付款、提现、KYC、私信和邮件都需要用户明确批准。

  • 不提供正式咨询、安全审计、法律、税务、财务、医疗建议。
  • 不自动提交 PR、赏金任务、平台 listing、邮件、私信、表单或付款。
