Codex 辅助问题排查模板包

一个可复制的 Codex 辅助问题排查模板包，包含问题收集清单、复现日志、提示词模板和适用边界。

这是一个可以直接复制使用的轻量模板包，用来把“小范围技术问题”整理成 Codex 更容易处理的形式。

它不是正式咨询服务，也不保证一定解决问题。它的价值在于：把问题描述、复现步骤、环境信息、错误日志和期望结果整理清楚，降低沟通成本。

适用场景

  • Hexo / GitHub Pages / Node.js 构建失败。
  • 静态站点样式、导航、图片、SEO 元数据异常。
  • 小型脚本、配置文件、Markdown 内容需要排查。
  • 你能提供仓库、日志、命令输出或可复现步骤。

不适用场景

  • 生产系统紧急故障。
  • 涉及隐私、密钥、公司内部代码或敏感数据的问题。
  • 需要正式安全审计、法律判断、财务判断或结果担保的任务。
  • 违法攻击、绕过风控、批量注册、刷量作弊等需求。
