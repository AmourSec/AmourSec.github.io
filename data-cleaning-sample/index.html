混乱表格到可用数据：一次虚拟数据清理示例

一个虚拟数据清理样例，展示如何识别混乱表格中的名称不一致、缺失字段、格式混杂和重复记录，并整理成可检查的数据。

这是一个数据清理方向的变现实验样品。示例里的数据全部是虚构的，不涉及真实个人信息。

目标不是保证数据绝对正确，而是展示一个可交付流程：识别问题、统一字段、标记不确定项、输出需要人工复核的清单。

混乱表格示例

客户 电话 预约日期 服务 金额
王小明 0912-333-888 5/21 清洁 800
小明王 0912333888 2026-05-21 家庭清洁 NT$800
李小姐 五月二十二日 维修 1200
Chen Wei 0988 111 222 2026/5/23 repair 1,200
陈伟 0988111222 05-23 维修 NT$1200
张三 0900-000-000 2026-05-24 清洁 待确认

问题诊断

问题 例子 处理方式
名称不一致 王小明 / 小明王 不自动合并，先标记为疑似重复
电话格式混杂 0912-333-888 / 0912333888 统一去除空格和连字符
日期格式混杂 5/21 / 2026-05-21 / 五月二十二日 能确定的统一为 ISO 日期，不能确定的标记复核
服务名混杂 清洁 / 家庭清洁 / repair 建立服务映射表
金额格式混杂 800 / NT$800 / 1,200 统一为数字，无法确定的保留备注
疑似重复 同电话、同日期、同金额 标记，不擅自删除
缺失字段 李小姐 缺电话 标记缺失，等待补充

安全清理流程

  1. 先备份原始表格，不直接覆盖。
  2. 明确哪些字段允许自动标准化，例如电话格式和金额格式。
  3. 对名称、身份、重复记录只标记，不自动合并或删除。
  4. 对推断出的日期、服务类型、金额加备注。
  5. 输出“需复核”清单，让人确认。
  6. 不处理真实身份证号、银行卡、病历、合同、密码、Token 等敏感信息。
  7. 最终结果要由数据拥有者确认。

可复制提示词

边界

  • 不处理真实个人隐私、医疗、财务、合同、账号密钥或公司内部敏感数据。
  • 不保证清理结果绝对准确，必须人工复核。
  • 不擅自删除、合并或覆盖原始数据。
  • 不替用户承担数据合规责任。
