常用命令速查

命令 说明
hexo new "标题" 创建新文章
hexo server 启动本地服务器
hexo generate 生成静态文件
hexo deploy 部署到远程仓库
hexo clean 清理缓存

  • 添加 SEO 优化
  • 集成统计分析
